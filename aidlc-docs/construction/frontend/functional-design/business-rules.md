> Backend の business-rules.md（BR-01〜13）を参照元とし、
> フロントエンドが実装すべき UI ルール・制約を定義する。

## FBR-01: ページアクセス制御（認証保護ルート）

| ルール ID | FBR-01 |
|---|---|
| カテゴリ | AuthProvider / ルーティング |
| 優先度 | 必須 |
| 参照 | BR-13 |

**保護ルート一覧**:

| パス | 認証要否 | 未認証時の挙動 |
|---|---|---|
| `/` | 不要 | — |
| `/seeds` | 不要 | — |
| `/seeds/[id]` | 不要 | — |
| `/louges` | 不要 | — |
| `/louges/[id]` | 不要 | — |
| `/seeds/new` | **必須** | `/login?redirect=/seeds/new` へリダイレクト |
| `/profile/[userId]` | 不要（閲覧のみ） | — |
| Logの投稿フォーム | **必須** | 同上リダイレクト |
| リアクションボタン | **必須** | 同上リダイレクト |

**実装ルール**:
- `redirect` クエリパラメータにリダイレクト元URLを保持する
- ログイン完了後、`redirect` に指定されたURLに戻る
- `redirect` パラメータは同一オリジンのURLのみ許可（オープンリダイレクト防止）

## FBR-02: SeedFormPage ステップ進行ルール

| ルール ID | FBR-02 |
|---|---|
| カテゴリ | SeedFormPage（FC-04）|
| 優先度 | 必須 |
| 参照 | BR-08 |

**ステップ構成（4ステップ固定）**:

| ステップ | 内容 | 進行条件 |
|---|---|---|
| Step 1 | タイプ選択（8タイプから1つ） | type が選択済みであること |
| Step 2 | 共通フィールド（タイトル・本文） | title: 1〜200文字、content: 1〜2000文字 |
| Step 3 | タグ付け（制限なし） | 任意（0件でも進める） |
| Step 4 | 確認画面 | — |

**バリデーションルール**:

| フィールド | ルール | エラーメッセージ |
|---|---|---|
| type | 必須（Step 1 で選択） | — |
| title | 必須、1〜200文字 | 「タイトルは200文字以内で入力してください」 |
| content | 必須、1〜2000文字 | 「本文は2000文字以内で入力してください」 |
| tags | 任意、制限なし | — |

**ステップナビゲーション**:
- 「次へ」ボタンはステップ内バリデーション通過時のみ活性化
- 「戻る」は常に活性（入力内容はリセットしない）
- Step 4（確認画面）から直接編集可能（各ステップへジャンプ）

## FBR-03: AI 知恵洗浄インラインサジェストルール

| ルール ID | FBR-03 |
|---|---|
| カテゴリ | SeedFormPage（FC-04）|
| 優先度 | 推奨 |
| 参照 | BR-07 |

**動作ルール**:
- 本文（content）フィールドの変更後 **800ms のデバウンス** で自動呼び出し
- API 呼び出し中はインジケーター表示（スピナー）
- サジェストは content 入力エリアの**直下にインライン表示**
- 各サジェストアイテムに「承認」「却下」ボタンを提供
- 「承認」クリックで content 内の固有名詞を抽象化候補に置換
- 「却下」クリックでそのサジェストを非表示
- API 失敗時はサジェストエリアを非表示にする（エラー表示しない、投稿はブロックしない）
- content が 10 文字未満の場合は呼び出しをスキップ

## FBR-04: GrowthIndicator 表示ルール

| ルール ID | FBR-04 |
|---|---|
| カテゴリ | GrowthIndicator（FC-09）|
| 優先度 | 必須 |
| 参照 | BR-04 |

**SVGアニメーション仕様**:

| GrowthStage | 表示内容 |
|---|---|
| seed | 種（丸いシルエット）のみ |
| sprout | 種 + 双葉が出始める |
| growth | 茎が伸び葉が増える |
| near_bloom | 蕾が付いた状態 |
| flowering | 花が咲いている（パルスアニメーション） |
| bloomed | 満開・発光エフェクト |

**アニメーション仕様**:
- ステージ変化時は前ステージからのトランジションアニメーション（0.5秒）
- `flowering` ステージのみパルス（繰り返し）アニメーション
- `bloomed` は静止した満開表示（アニメーション停止）
- SVG は `64px × 64px` をデフォルトサイズとし、`size` プロップでオーバーライド可能

**Realtime 更新**:
- SeedDetailPage（FC-03）で Supabase Realtime を購読
- `seeds` テーブルの `stage` フィールド変更イベント受信時に即座に表示更新
- フィード（SeedFeedPage）では Realtime 購読なし（ポーリングなし、次回ロード時に反映）

## FBR-05: 無限スクロール動作ルール

| ルール ID | FBR-05 |
|---|---|
| カテゴリ | SeedFeedPage（FC-02）、LougeListPage（FC-06）|
| 優先度 | 必須 |
| 参照 | BR-09 |

**動作ルール**:
- 1回あたりのロード件数: **20件**
- スクロール位置がリスト末尾から **200px 以内** に達したら次ページロード
- ロード中はスケルトンローダーを表示
- 最終ページ到達時は「すべて読み込みました」テキストを表示
- 新着順ソート固定（SeedFeedPage: デフォルト、フィルタなし）
- エラー時は「再試行」ボタンを表示（自動リトライなし）

## FBR-06: 通知既読ルール

| ルール ID | FBR-06 |
|---|---|
| カテゴリ | NotificationDropdown（FC-10）|
| 優先度 | 必須 |
| 参照 | BR-10 |

**既読タイミング**:
- NotificationDropdown を開いた瞬間に、全未読通知を一括既読（`PUT /notifications/read-all` を呼び出し）
- ドロップダウンを閉じた後も既読状態は維持

**表示ルール**:
- ヘッダーの通知アイコンに未読件数バッジを表示（0件の場合は非表示）
- ドロップダウン内は最新20件を表示（それ以上はスクロール）
- Supabase Realtime で `notifications` テーブルの INSERT を購読
- 新着通知受信時は未読バッジ数を即座に更新（ローカル状態を更新）

## FBR-07: Fork ボタン表示・制御ルール

| ルール ID | FBR-07 |
|---|---|
| カテゴリ | LougeDetailPage（FC-07）|
| 優先度 | 必須 |
| 参照 | BR-12 |

**表示条件**:
- `louge.status === 'published'` のときのみ Fork ボタンを表示
- ログインユーザーのみ Fork ボタンを表示（非ログイン時は非表示）
- Fork クリック時: SeedFormPage へ遷移（`parent_louge_id` を State 経由で渡す）

## FBR-08: エラーハンドリングルール

| ルール ID | FBR-08 |
|---|---|
| カテゴリ | 全コンポーネント |
| 優先度 | 必須 |

**トースト通知方式（全API エラー共通）**:
- 表示位置: 画面右下
- 自動消滅: 3秒後
- スタイル: エラー（赤）/ 成功（緑）/ 情報（青）
- 複数エラー時は縦に積み上げ表示（最大3件）

**エラーメッセージ定義**:

| HTTPステータス | メッセージ |
|---|---|
| 401 Unauthorized | 「ログインが必要です」|
| 403 Forbidden | 「この操作は許可されていません」|
| 404 Not Found | 「コンテンツが見つかりませんでした」|
| 422 Unprocessable Entity | 「入力内容を確認してください」|
| 500 Server Error | 「サーバーエラーが発生しました。しばらく後に再試行してください」|
| Network Error | 「接続に失敗しました。ネットワーク接続を確認してください」|

**特例（トースト以外の処理）**:
- 401 エラーは `/login?redirect=...` へリダイレクト
- AI 知恵洗浄 API エラーはトーストなし（FBR-03 参照）

## FBR-09: レスポンシブ対応ルール

| ルール ID | FBR-09 |
|---|---|
| カテゴリ | 全ページ |
| 優先度 | 必須 |

**対応方針（主要ページのみ両対応）**:

| ページ | モバイル対応 | ブレークポイント |
|---|---|---|
| SeedFeedPage（FC-02） | ○ | sm (640px) / md (768px) |
| SeedDetailPage（FC-03） | ○ | sm / md |
| LougeListPage（FC-06） | ○ | sm / md |
| LougeDetailPage（FC-07） | ○ | sm / md |
| ProfilePage（FC-08） | ○ | sm / md |
| SeedFormPage（FC-04） | △（最低限） | sm |
| 認証ページ | ○ | sm |

**レイアウトルール**:
- モバイル（< 640px）: シングルカラム、ナビゲーションはボトムナビゲーション
- タブレット（640px〜）: 2カラムレイアウト可
- デスクトップ（1024px〜）: サイドバー付き3カラム可

## FBR-10: デザインシステム定義ルール

| ルール ID | FBR-10 |
|---|---|
| カテゴリ | Code Generation 先行ステップ |
| 優先度 | 必須 |

**方針**: Code Generation の **最初のステップ**として Tailwind デザインシステムを定義し、全コンポーネントはそれに準拠する。

**定義対象**:
- カラーパレット（brand / neutral / semantic colors）
- タイポグラフィスケール（font-size / font-weight / line-height）
- スペーシング・ボーダー・シャドウ等のトークン
- 共通UIコンポーネントのスタイル（Button / Card / Badge 等）
- `tailwind.config.ts` に `theme.extend` として集約

**制約**:
- 絵文字をUIに使用しない（アイコンライブラリ or テキストで代替）
- リアクションボタン（insight / agree / helpful）はアイコン or テキストラベルで表現
