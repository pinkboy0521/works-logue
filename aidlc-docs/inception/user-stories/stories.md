# Works Logue — ユーザーストーリー

## 構成方針
- **整理方法**: ユーザージャーニーベース（登録 → Seed投稿 → Log対話 → Louge開花 → Fork）
- **粒度**: 中程度（1スプリント内で完結する機能単位）
- **受け入れ条件フォーマット**: Given / When / Then（BDDスタイル）
- **優先度**: 高 / 中 / 低
- **重点領域**: Log対話フロー（詳細） + Louge開花体験（詳細）

---

## エピック 0: 非ログインユーザーの閲覧体験

### US-000: Seed一覧の閲覧（非ログイン）
**As a** 訪問者（非ログインユーザー）
**I want to** ログインせずにSeed一覧を閲覧したい
**So that** プラットフォームの価値を確認してから登録を判断できる

**優先度**: 高

**受け入れ条件**:
- Given: 未ログインのユーザーがトップページにアクセスしたとき
- When: Seed一覧フィードが表示されたとき
- Then: 投稿内容・成長ステージ・タグが閲覧でき、Log投稿ボタンはログインを促す状態で表示される

---

### US-001: Louge一覧・詳細の閲覧（非ログイン）
**As a** 訪問者
**I want to** ログインせずにLougeの知識記事を読みたい
**So that** 有益な知識を得られるかどうかを評価できる

**優先度**: 高

**受け入れ条件**:
- Given: 未ログインのユーザーがLouge一覧ページにアクセスしたとき
- When: Lougeの一覧・詳細ページを閲覧したとき
- Then: 記事本文・開花貢献者一覧・元Seed/Logへのリンクが表示される

## エピック 1: 登録・認証フロー

### US-101: メール登録
**As a** 新規ユーザー
**I want to** メールアドレスとパスワードで登録したい
**So that** Works Logueのすべての機能を利用できる

**優先度**: 高

**受け入れ条件**:

- When: メールアドレス・パスワード・ユーザー名を入力して送信したとき
- Then: Supabase Authにアカウントが作成され、確認メールが送信され、ログイン済み状態になる

---

**As a** ユーザー
**I want to** Googleアカウントでサインインしたい
**So that** パスワード管理の手間なく素早くログインできる

**優先度**: 中

**受け入れ条件**:
- Given: ログインページでGoogleログインボタンをクリックしたとき
- When: Googleアカウントで認証が完了したとき
- Then: Works Logueにログイン済みでリダイレクトされ、プロフィールが自動作成される

---

### US-103: プロフィール設定
**As a** 登録済みユーザー
**I want to** プロフィール（アバター・自己紹介・業種）を設定したい
**So that** 自分が誰かをコミュニティに伝え、貢献の文脈を明示できる

**優先度**: 高

**受け入れ条件**:
- Given: ログイン済みユーザーがプロフィール設定ページにアクセスしたとき
- When: アバター画像・自己紹介文・所属業種を入力して保存したとき
- Then: プロフィールページに反映され、Logやbadge情報も同一ページに表示される

## エピック 2: Seed投稿フロー（種蒔き）

### US-201: Seedタイプ選択と投稿
**As a** Seeker
**I want to** 8種類のSeedタイプから選んで投稿したい
**So that** 自分の問いや悩みを適切な形で表現できる

**優先度**: 高

**受け入れ条件**:
- Given: ログイン済みユーザーがSeed投稿画面にアクセスしたとき
- When: タイプ（疑問/悩み/失敗/仮説/比較/違和感/シェア/実践報告）を選択し、ガイドに従ってフォームを入力して投稿したとき
- Then: Seedが作成されフィードに表示され、成長ステージが「Seed」として記録される

---

### US-202: Seedへのタグ付け
**As a** Seeker
**I want to** Seedに業種・テーマタグを付けたい
**So that** 関連する専門家に届きやすくなる

**優先度**: 高

**受け入れ条件**:
- Given: Seed投稿フォームを入力中のとき
- When: 業種・テーマカテゴリからタグを選択（または入力）して投稿したとき
- Then: Seed詳細ページとフィードにタグが表示され、タグでフィルタ検索が可能になる

---

### US-203: AIによる知恵洗浄（リアルタイム）
**As a** Seeker
**I want to** 社名・個人名を含む入力をAIに自動検知・抽象化提案してもらいたい
**So that** 安全に実例を投稿できる

**優先度**: 中

**受け入れ条件**:
- Given: Seed投稿フォームにテキストを入力しているとき
- When: 固有名詞（社名・人名）が含まれると検知されたとき
- Then: AIが抽象化された表現（「大手メーカーA社」など）を提案し、ユーザーが確認・承認できる

---

### US-204: Seed一覧フィードの閲覧
**As a** ユーザー（Seeker / Contributor）
**I want to** Seed一覧を成長ステージやタグでフィルタして見たい
**So that** 自分に関係する問いを見つけやすい

**優先度**: 高

**受け入れ条件**:
- Given: Seed一覧ページにアクセスしたとき
- When: 成長ステージ・タグ・業種でフィルタを適用したとき
- Then: 条件に合致するSeedのみが一覧表示され、各Seedの成長ステージ・Log数が表示される

## エピック 3: Log対話フロー（水やり）★詳細

### US-301: Seedへのログ投稿
**As a** Contributor
**I want to** Seedに対してLog（コメント・実務経験の共有）を投稿したい
**So that** 自分の知見を問いに届け、貢献として記録してもらえる

**優先度**: 高

**受け入れ条件**:
- Given: ログイン済みユーザーがSeed詳細ページを閲覧しているとき
- When: Log入力フォームにテキストを入力して投稿ボタンを押したとき
- Then: Logが保存され詳細ページに表示され、Seed投稿者に通知が送られ、投稿者のLog貢献数が加算される

---

### US-302: Logへの返信（スレッド）
**As a** Contributor
**I want to** 他のContributorのLogに返信したい
**So that** 深い議論や補足説明ができる

**優先度**: 中

**受け入れ条件**:
- Given: Seed詳細ページでLogの一覧を閲覧しているとき
- When: 特定のLogに「返信」ボタンを押してテキストを入力し投稿したとき
- Then: 返信がスレッド形式で親Logの下にネスト表示され、元のLog投稿者に通知が送られる

---

### US-303: Logへのリアクション
**As a** ユーザー
**I want to** 役に立ったLogに「共感」「役立った」などのリアクションをしたい
**So that** 質の高い貢献が可視化され、インサイト・スコアに反映される

**優先度**: 低

**受け入れ条件**:
- Given: ログイン済みユーザーがSeed詳細ページでLogを閲覧しているとき
- When: Logのリアクションボタン（共感・役立った等）をクリックしたとき
- Then: リアクション数がリアルタイムで更新され、Log投稿者のスコアに加算される

---

### US-304: 成長ステージのリアルタイム表示
**As a** Seeker / Contributor
**I want to** 自分が貢献しているSeedの成長ステージ変化をリアルタイムで知りたい
**So that** 開花に近づく興奮・達成感を体験できる

**優先度**: 高

**受け入れ条件**:
- Given: ユーザーがSeed詳細ページを閲覧しているとき
- When: 新しいLogが投稿されてステージ進行条件を満たしたとき
- Then: 成長ステージのビジュアルインジケーター（Seed→Sprout1→...）がリアルタイムで更新される

---

### US-305: 開花間近の参加促進通知
**As a** Contributor
**I want to** 開花基準に近づいたSeedの通知を受け取りたい
**So that** 「あと少しで開花」のタイミングに参加して貢献できる

**優先度**: 中

**受け入れ条件**:
- Given: Seedが開花基準の80%以上の条件を満たしたとき
- When: ユーザーが通知設定をオンにしているとき
- Then: 「このSeedが開花間近です。あなたの知見で完成させませんか？」という通知が届く

---

### US-306: Log投稿者・タイムスタンプの表示
**As a** ユーザー
**I want to** 各Logの投稿者名・投稿日時を確認したい
**So that** 誰のどんな経験かを文脈込みで理解できる

**優先度**: 高

**受け入れ条件**:
- Given: Seed詳細ページでLog一覧を閲覧しているとき
- When: Logが表示されたとき
- Then: 各Logに投稿者のアバター・ユーザー名・投稿日時が表示される

## エピック 4: Louge開花体験★詳細

### US-401: 開花判定の自動実行
**As a** システム
**I want to** Seedに設定された開花基準（Log数・参加者数・多様性スコア）を満たしたとき自動的にLouge生成を開始したい
**So that** ユーザーの手動操作なしに知識昇華が起こる

**優先度**: 高

**受け入れ条件**:
- Given: SeedのLog数・参加者数・多様性スコアが開花基準を満たしたとき
- When: 開花判定エンジンが条件達成を検知したとき
- Then: Claude APIへのLouge生成リクエストが自動発行され、Seedのステータスが「開花中」に変わる

---

### US-402: AI Louge生成と公開
**As a** Seeker / Contributor
**I want to** Seedが開花し、蓄積されたLog群からAIがWikipedia型の知識記事（Louge）を自動生成してほしい
**So that** 散らばった対話が価値ある構造化知識として昇華される

**優先度**: 高

**受け入れ条件**:
- Given: 開花判定が実行されClaude APIが呼び出されたとき
- When: Louge生成が完了したとき
- Then: Lougeページが生成・公開され、Seedページにリンクが表示され、貢献者全員に「開花通知」が届く

---

### US-403: Louge生成中の状態表示
**As a** ユーザー
**I want to** Louge生成中であることを確認したい
**So that** AI処理の進行状況がわかりブラウザを閉じずに待てる

**優先度**: 高

**受け入れ条件**:
- Given: 開花判定後にSeed詳細ページを閲覧しているとき
- When: Louge生成が処理中のとき
- Then: 「Louge生成中...」というインジケーターが表示され、生成完了後に自動でLougeページへリダイレクトまたは通知される

---

### US-404: Lougeページの閲覧
**As a** ユーザー（Seeker / 訪問者）
**I want to** 生成されたLougeの知識記事を読みたい
**So that** 集合知として整理された洞察を手軽に得られる

**優先度**: 高

**受け入れ条件**:
- Given: ユーザーがLougeページにアクセスしたとき
- When: Lougeが公開状態のとき
- Then: タイトル・本文（構造化テキスト）・元SeedとLog群へのリンク・開花貢献者一覧が表示される

---

### US-405: Louge一覧・検索
**As a** Seeker
**I want to** タグ・業種・キーワードでLougeを検索したい
**So that** 自分の課題に関係するLougeをすぐに見つけられる

**優先度**: 高

**受け入れ条件**:
- Given: ユーザーがLouge一覧ページにアクセスしたとき
- When: タグ・業種カテゴリ・キーワードで検索フィルタを適用したとき
- Then: 条件に一致するLougeが一覧表示され、タイトル・タグ・投稿日・貢献者数が確認できる

---

### US-406: 開花貢献者の表示
**As a** Contributor
**I want to** Lougeページに自分の名前が「開花貢献者」として掲載されてほしい
**So that** 知識の共創に自分が関わったことが永続的に記録される

**優先度**: 高

**受け入れ条件**:
- Given: ユーザーがLougeページを閲覧しているとき
- When: Lougeが公開状態のとき
- Then: Seed投稿者と上位Log投稿者が「開花貢献者」として名前・アバター付きで表示される

## エピック 5: Fork（再播種）フロー

### US-501: LougeからForkしてSeedを作成
**As a** Seeker
**I want to** 読んだLougeを実践した結果を「Fork Seed」として投稿したい
**So that** 知識の実践フィードバックループを回し、次の知識進化を起こせる

**優先度**: 高

**受け入れ条件**:
- Given: ログイン済みユーザーがLougeページを閲覧しているとき
- When: 「Forkして種を蒔く」ボタンを押してSeed投稿フォームに遷移したとき
- Then: 親LougeのIDが自動付与されたSeed投稿フォームが開き、投稿すると親Lougeの「派生Seed一覧」に表示される

---

### US-502: 派生Seedの表示
**As a** ユーザー
**I want to** LougeページからForkされた派生Seedを確認したい
**So that** 知識が実践されて次の問いへと連鎖する様子を確認できる

**優先度**: 高

**受け入れ条件**:
- Given: ユーザーがLougeページを閲覧しているとき
- When: Lougeからのフォーク済みSeedが存在するとき
- Then: Lougeページの下部に「派生Seed一覧」セクションが表示され、Fork Seedのタイトル・成長ステージが確認できる

---

### US-503: ForkSeedから親Lougeへのリンク
**As a** ユーザー
**I want to** ForkされたSeedの詳細ページで親Lougeを確認したい
**So that** このSeedがどの知識から生まれたかを辿れる

**優先度**: 高

**受け入れ条件**:
- Given: ユーザーがFork SeedのSeed詳細ページを閲覧しているとき
- When: ページが表示されたとき
- Then: 「このSeedは [Lougeタイトル] からForkされました」という親Lougeへのリンクが表示される

---

## エピック 6: インサイト・スコアとバッジ

### US-601: インサイト・スコアの自動計算
**As a** Contributor
**I want to** Seed投稿・Log投稿・開花への貢献度に応じてスコアが自動加算されてほしい

**As a** Contributor
**I want to** Louge開花に貢献したときにバッジをもらいたい

---

### US-603: プロフィールでのスコア・バッジ・貢献履歴表示

**I want to** プロフィールページで自分のスコア・バッジ・貢献したSeed/Lougeの履歴を確認したい
**So that** 自分の成長とポートフォリオとして活用できる

**優先度**: 高

**受け入れ条件**:

- When: ページが表示されたとき
- Then: インサイト・スコア総計・取得バッジ一覧・貢献したSeed/Louge一覧（Log数・貢献日付付き）が表示される
